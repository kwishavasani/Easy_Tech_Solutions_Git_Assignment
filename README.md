**Project Overview:**
This project is developed as part of a Git & GitHub assignment to demonstrate the practical implementation of version control and collaborative development.


Here, we have created 2 Web Pages for Easy Tech Solutions : 
Register Page
Dashboard Page 


**Company Overview:**
Easy Tech Solutions is a software company focused on delivering high-quality digital solutions through:
Automation Testing
QA & Performance Engineering
DevOps & CI/CD Pipelines
Secure Software Development
Tagline:
Engineering Quality. Delivering Confidence.


**Assignment’s Objective:**
To create a local project structure.
Implement the Login and Dashboard Page for the authentication flow.
Use Git commands for version control.
Sync project with GitHub repository.

 
**Tech Used:**
HTML 5
CSS3
JavaScript
Git & GitHub


**Features Implemented:-**
Login Page
Modern UI with split layout
Username & password input
Basic validation
Social login placeholders (Google, GitHub)

 **Dashboard Page:**
Sidebar navigation
Welcome message with username
QA metrics display:
Test Cases
Bugs Logged
Build Status
Automation Coverage
Logout functionality

**Application Flow:-** 
User opens login.html
Enters credentials (Random Input Field)
It gets redirected to dashboard.html
Username displayed dynamically
User can log out → returns to login page


 **Conclusion:-** 
This project demonstrates :
How to build UI components for real-world scenarios
Importance and Usage of Git for Version Control
Collaborate using GitHub for seamless code sharing.
